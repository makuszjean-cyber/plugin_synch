Polices Poppins (Google Fonts) pour le plugin sketcher.
Les fichiers .ttf sont chargés au démarrage du plugin pour un rendu cohérent.

Variantes incluses : Regular, Light, Italic, Medium.
Pour ajouter d'autres variantes (Bold, etc.), téléchargez les TTF depuis :
https://github.com/google/fonts/tree/main/ofl/poppins
et placez-les dans ce dossier. Elles seront chargées automatiquement
si leur nom est ajouté à FONT_FILES dans core/font_loader.py.
